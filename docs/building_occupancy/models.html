building_occupancy.models

Linear models for building occupancy and the baselines they are compared against.

All models share one interface::

model.fit(df, y)        # df: modelling dataset rows, y: target values
model.predict(df)       # -> numpy array, clipped at 0 (headcount cannot be negative)
Linear numerical method

MassBalanceRegression fits the well-mixed-zone CO2 mass balance

V dC/dt = N G - Q (C - C_out)    =>    N = a dC/dt + b C + c

(V zone volume, Q ventilation flow, G CO2 generation per person, C_out supply CO2) by linear least squares, solved with our own QR-decomposition + back-substitution solver (solve_lstsq_qr()). solve_lstsq_normal() (normal equations + Cholesky) is provided for the numerical stability comparison.

Machine learning

RidgeRegression is L2-regularised linear regression on all environmental features, with the penalty chosen by time-ordered cross-validation (scikit-learn).

PolynomialRidgeRegression extends it to polynomial features of degree 1-4. Because the number of terms grows combinatorially, it computes the whole regularisation path from a single SVD per fold (ridge_path_svd()) instead of refitting for every penalty.

 46# ---------------------------------------------------------------- numerical solvers

 48# Relative pivot size below which a triangular factor is treated as singular. For the R
 49# factor of a QR decomposition this means cond(X) > ~1e10: coefficients would keep fewer
 50# than ~6 significant digits in double precision, so the design is effectively
 51# rank-deficient (exact collinearities leave pivots of ~1e-14 from rounding alone).
 52SINGULAR_RTOL = 1e-10
 53
 54
 55def back_substitution(R, b, rtol=SINGULAR_RTOL):
 56    """Solve ``R x = b`` for upper-triangular ``R``.
 57
 58    Parameters
 59    ----------
 60    R : (n, n) array_like
 61        Upper-triangular matrix.
 62    b : (n,) array_like
 63        Right-hand side.
 64    rtol : float
 65        Singularity tolerance relative to the largest diagonal entry.
 66
 67    Returns
 68    -------
 69    numpy.ndarray
 70        Solution ``x``.
 71
 72    Raises
 73    ------
 74    numpy.linalg.LinAlgError
 75        If ``R`` is numerically singular (a diagonal entry is below
 76        ``rtol * max|diag(R)|``), i.e. the design matrix is (nearly) rank deficient.
 77    """
 78    R, b = np.asarray(R, float), np.asarray(b, float)
 79    n = R.shape[0]
 80    diag = np.abs(np.diag(R))
 81    if diag.min() <= rtol * diag.max():
 82        raise np.linalg.LinAlgError("matrix is numerically singular (rank-deficient design)")
 83    x = np.zeros(n)
 84    for i in range(n - 1, -1, -1):
 85        x[i] = (b[i] - R[i, i + 1:] @ x[i + 1:]) / R[i, i]
 86    return x
 87
 88
 89def forward_substitution(L, b, rtol=SINGULAR_RTOL):
 90    """Solve ``L x = b`` for lower-triangular ``L``.
 91
 92    Parameters
 93    ----------
 94    L : (n, n) array_like
 95        Lower-triangular matrix.
 96    b : (n,) array_like
 97        Right-hand side.
 98    rtol : float
 99        Singularity tolerance relative to the largest diagonal entry.
100
101    Returns
102    -------
103    numpy.ndarray
104        Solution ``x``.
105
106    Raises
107    ------
108    numpy.linalg.LinAlgError
109        If ``L`` is numerically singular.
110    """
111    L, b = np.asarray(L, float), np.asarray(b, float)
112    n = L.shape[0]
113    diag = np.abs(np.diag(L))
114    if diag.min() <= rtol * diag.max():
115        raise np.linalg.LinAlgError("matrix is numerically singular")
116    x = np.zeros(n)
117    for i in range(n):
118        x[i] = (b[i] - L[i, :i] @ x[:i]) / L[i, i]
119    return x

122def solve_lstsq_qr(X, y):
123    """Least-squares solution of ``X beta ~= y`` via Householder QR.
124
125    ``X = Q R`` (reduced), so the normal equations reduce to ``R beta = Q^T y``. This
126    works with ``cond(X)`` rather than ``cond(X)^2``, so it is the stable choice.
127
128    Parameters
129    ----------
130    X : (m, n) array_like
131        Design matrix, ``m >= n``, full column rank.
132    y : (m,) array_like
133        Observations.
134
135    Returns
136    -------
137    numpy.ndarray
138        Coefficients ``beta`` of length ``n``.
139    """
140    X, y = _check_design(X, y)
141    Q, R = np.linalg.qr(X, mode="reduced")
142    return back_substitution(R, Q.T @ y)
143
144
145def solve_lstsq_normal(X, y):
146    """Least-squares solution via the normal equations ``X^T X beta = X^T y``.
147
148    Solved with a Cholesky factorisation ``X^T X = L L^T`` and two triangular solves.
149    Cheaper than QR but squares the condition number, so it loses accuracy when the
150    columns of ``X`` are nearly collinear. Provided for comparison only.
151
152    Parameters
153    ----------
154    X : (m, n) array_like
155        Design matrix, full column rank.
156    y : (m,) array_like
157        Observations.
158
159    Returns
160    -------
161    numpy.ndarray
162        Coefficients ``beta``.
163    """
164    X, y = _check_design(X, y)
165    L = np.linalg.cholesky(X.T @ X)
166    return back_substitution(L.T, forward_substitution(L, X.T @ y))

169def ridge_path_svd(X, y, alphas):
170    """Ridge coefficients for many penalties from a single thin SVD.
171
172    With ``X = U S V^T``, the ridge solution for penalty ``alpha`` is
173    ``beta = V diag(s / (s^2 + alpha)) U^T y``. One SVD (~``6 m n^2 + 20 n^3`` flops,
174    Golub & Van Loan, *Matrix Computations*, 4th ed., sec. 8.6) therefore gives every
175    penalty, instead of one factorisation per penalty. Working from the SVD of ``X``
176    rather than ``X^T X`` also avoids squaring the condition number.
177
178    ``X`` and ``y`` should be centred; no intercept is fitted.
179
180    Parameters
181    ----------
182    X : (m, n) array_like
183        Design matrix (any shape; ``n > m`` is allowed).
184    y : (m,) array_like
185        Observations.
186    alphas : array_like
187        Penalties, all > 0.
188
189    Returns
190    -------
191    numpy.ndarray
192        Coefficients, shape ``(n, len(alphas))``.
193    """
194    X, y = np.asarray(X, float), np.asarray(y, float)
195    alphas = np.atleast_1d(np.asarray(alphas, float))
196    if X.ndim != 2 or y.ndim != 1 or X.shape[0] != y.shape[0]:
197        raise ValueError(f"incompatible shapes X{X.shape}, y{y.shape}")
198    if np.any(alphas <= 0):
199        raise ValueError("ridge penalties must be positive")
200    if not (np.isfinite(X).all() and np.isfinite(y).all()):
201        raise ValueError("X and y must not contain NaN or inf")
202    U, s, Vt = np.linalg.svd(X, full_matrices=False)
203    shrink = s[:, None] / (s[:, None] ** 2 + alphas[None, :])   # (k, n_alphas)
204    return Vt.T @ (shrink * (U.T @ y)[:, None])
205

207def n_polynomial_terms(n_features, degree):
208    """Number of polynomial terms of degree 1..``degree`` in ``n_features`` variables.
209
210    Parameters
211    ----------
212    n_features, degree : int
213
214    Returns
215    -------
216    int
217        ``C(n_features + degree, degree) - 1`` (all monomials except the constant).
218    """
219    return comb(n_features + degree, degree) - 1

222def _check_design(X, y):
223    """Validate shapes and finiteness of a least-squares problem."""
224    X, y = np.asarray(X, float), np.asarray(y, float)
225    if X.ndim != 2 or y.ndim != 1 or X.shape[0] != y.shape[0]:
226        raise ValueError(f"incompatible shapes X{X.shape}, y{y.shape}")
227    if X.shape[0] < X.shape[1]:
228        raise ValueError("underdetermined system: fewer observations than coefficients")
229    if not (np.isfinite(X).all() and np.isfinite(y).all()):
230        raise ValueError("X and y must not contain NaN or inf")
231    return X, y

236def time_features(df, harmonics=2):
237    """Smooth time-of-day features: sine/cosine pairs, a weekend flag and their interaction.
238
239    Parameters
240    ----------
241    df : pandas.DataFrame
242        Must contain ``hour_local`` (0-24) and ``weekend`` (bool).
243    harmonics : int
244        Number of sine/cosine pairs.
245
246    Returns
247    -------
248    pandas.DataFrame
249        ``2 * harmonics * 2 + 1`` columns aligned with ``df``.
250    """
251    ang = 2 * np.pi * df["hour_local"].to_numpy(float) / 24
252    we = df["weekend"].to_numpy(float)
253    out = {"weekend": we}
254    for k in range(1, harmonics + 1):
255        for name, f in (("sin", np.sin), ("cos", np.cos)):
256            v = f(k * ang)
257            out[f"{name}{k}"] = v
258            out[f"weekend:{name}{k}"] = v * we
259    return pd.DataFrame(out, index=df.index)

279class TimeOfDayBaseline:
280    """Mean target for each (hour of day, weekday/weekend) cell; uses no sensor data.
281
282    This is the bar an environmental model must beat to show the sensors add information
283    beyond the building's routine.
284    """
285
286    name = "Time-of-day baseline"
287
288    def fit(self, df, y):
289        """Average ``y`` within each hour x day-type cell. Returns ``self``."""
290        key = self._key(df)
291        self.cells_ = pd.Series(np.asarray(y, float), index=key).groupby(level=[0, 1]).mean()
292        self.fallback_ = float(np.mean(y))
293        return self
294
295    def predict(self, df):
296        """Cell mean for each row; overall training mean for cells never seen."""
297        return self.cells_.reindex(self._key(df)).fillna(self.fallback_).to_numpy()
298
299    @staticmethod
300    def _key(df):
301        """(floor of local hour, weekend flag) index used to look up cell means."""
302        return pd.MultiIndex.from_arrays([np.floor(df["hour_local"]).astype(int), df["weekend"].astype(bool)])

307class LinearLeastSquares:
308    """Ordinary least squares with intercept, solved by :func:`solve_lstsq_qr`.
309
310    Parameters
311    ----------
312    features : list of str
313        Columns of the dataset used as regressors. Rows must not contain NaN.
314    solver : {"qr", "normal"}
315        Least-squares solver.
316    name : str, optional
317        Display name.
318
319    Attributes
320    ----------
321    coef_ : pandas.Series
322        Fitted coefficients, including ``intercept``.
323    condition_number_ : float
324        2-norm condition number of the training design matrix.
325    """
326
327    def __init__(self, features, solver="qr", name=None):
328        if solver not in ("qr", "normal"):
329            raise ValueError("solver must be 'qr' or 'normal'")
330        self.features = list(features)
331        self.solver = solver
332        self.name = name or f"OLS ({', '.join(self.features)})"
333
334    def _design(self, df):
335        """Design matrix ``[1, features]``; raises ``ValueError`` on missing columns."""
336        missing = set(self.features) - set(df.columns)
337        if missing:
338            raise ValueError(f"dataset is missing features: {sorted(missing)}")
339        X = df[self.features].to_numpy(float)
340        return np.column_stack([np.ones(len(X)), X])
341
342    def fit(self, df, y):
343        """Fit coefficients by least squares. Returns ``self``."""
344        X = self._design(df)
345        solve = solve_lstsq_qr if self.solver == "qr" else solve_lstsq_normal
346        beta = solve(X, np.asarray(y, float))
347        self.coef_ = pd.Series(beta, index=["intercept", *self.features])
348        self.condition_number_ = float(np.linalg.cond(X))
349        return self
350
351    def predict(self, df):
352        """Linear prediction, clipped at zero."""
353        return np.clip(self._design(df) @ self.coef_.to_numpy(), 0, None)

356class MassBalanceRegression(LinearLeastSquares):
357    """Occupancy from the CO2 mass balance: ``N = a dC/dt + b C + c``.
358
359    Derived from ``V dC/dt = N G - Q (C - C_out)`` for a well-mixed zone with
360    ``C`` in ppm and ``dC/dt`` in ppm/h, giving ``a = V / (G 1e6)``,
361    ``b = Q / (G 1e6)`` and ``c = -b C_out``.
362    """
363
364    def __init__(self, solver="qr"):
365        super().__init__(MASS_BALANCE_FEATURES, solver=solver, name="CO2 mass balance (OLS)")
366
367    def implied_physics(self, co2_generation_m3_per_h=config.CO2_GENERATION_M3_PER_H):
368        """Physical quantities implied by the fitted coefficients.
369
370        Parameters
371        ----------
372        co2_generation_m3_per_h : float
373            CO2 generation per person (m3/h).
374
375        Returns
376        -------
377        dict
378            ``volume_m3`` (V), ``ventilation_m3_per_h`` (Q), ``air_changes_per_h`` (Q/V)
379            and ``supply_co2_ppm`` (C_out). A physically consistent fit has V, Q > 0 and
380            C_out near outdoor CO2 (~420 ppm).
381        """
382        a, b, c = self.coef_["dco2_dt"], self.coef_["co2"], self.coef_["intercept"]
383        g = co2_generation_m3_per_h * 1e6
384        volume, flow = a * g, b * g
385        return {
386            "volume_m3": volume,
387            "ventilation_m3_per_h": flow,
388            "air_changes_per_h": flow / volume if volume else np.nan,
389            "supply_co2_ppm": -c / b if b else np.nan,
390        }

393class RidgeRegression:
394    """L2-regularised linear regression with time-ordered selection of the penalty.
395
396    Pipeline: median imputation -> standardisation -> ridge. The penalty ``alpha`` is
397    chosen from ``alphas`` by :class:`sklearn.model_selection.TimeSeriesSplit` cross
398    validation on the training data only (minimising mean absolute error).
399
400    Parameters
401    ----------
402    features : list of str
403        Environmental feature columns (may contain NaN).
404    include_time : bool
405        Also use :func:`time_features`.
406    alphas : array_like
407        Candidate penalties.
408    inner_splits : int
409        Number of time-series splits for choosing ``alpha``.
410    name : str, optional
411        Display name.
412
413    Attributes
414    ----------
415    alpha_ : float
416        Selected penalty.
417    coef_ : pandas.Series
418        Coefficients on the standardised features (comparable magnitudes).
419    """
420
421    def __init__(self, features=ENV_FEATURES, include_time=False, alphas=config.RIDGE_ALPHAS,
422                 inner_splits=config.RIDGE_INNER_SPLITS, name=None):
423        self.features = list(features)
424        self.include_time = include_time
425        self.alphas = np.asarray(alphas, float)
426        self.inner_splits = inner_splits
427        self.name = name or ("Ridge (environment + time)" if include_time else "Ridge (environment)")
428
429    def _design(self, df):
430        """Feature table (environmental columns, plus time features if enabled); raises on missing columns."""
431        missing = set(self.features) - set(df.columns)
432        if missing:
433            raise ValueError(f"dataset is missing features: {sorted(missing)}")
434        X = df[self.features].astype(float)
435        if self.include_time:
436            X = pd.concat([X, time_features(df)], axis=1)
437        return X
438
439    def fit(self, df, y):
440        """Choose ``alpha`` by time-series CV, then refit on all of ``df``. Returns ``self``."""
441        X = self._design(df)
442        pipe = make_pipeline(SimpleImputer(strategy="median"), StandardScaler(), Ridge())
443        search = GridSearchCV(pipe, {"ridge__alpha": self.alphas},
444                              cv=TimeSeriesSplit(n_splits=self.inner_splits),
445                              scoring="neg_mean_absolute_error")
446        search.fit(X, np.asarray(y, float))
447        self.model_ = search.best_estimator_
448        self.alpha_ = float(search.best_params_["ridge__alpha"])
449        self.coef_ = pd.Series(self.model_[-1].coef_, index=X.columns)
450        return self
451
452    def predict(self, df):
453        """Ridge prediction, clipped at zero."""
454        return np.clip(self.model_.predict(self._design(df)), 0, None)

457class _PolynomialDesign:
458    """Training-set preprocessing for polynomial ridge: impute, scale, expand, scale.
459
460    Inputs are standardised *before* expansion so powers of large raw values (CO2 ~ 450 ppm)
461    do not make the design matrix ill-conditioned, and the expanded terms are standardised
462    again so the ridge penalty treats every term equally. All statistics come from the
463    training rows only.
464    """
465
466    def __init__(self, degree):
467        self.degree = degree
468
469    def fit_transform(self, raw):
470        """Learn preprocessing from ``raw`` (n x features array) and return the design."""
471        self.median_ = np.nanmedian(raw, axis=0)
472        filled = np.where(np.isnan(raw), self.median_, raw)
473        self.mean_, self.std_ = filled.mean(axis=0), _safe_std(filled)
474        self.poly_ = PolynomialFeatures(self.degree, include_bias=False)
475        expanded = self.poly_.fit_transform((filled - self.mean_) / self.std_)
476        self.emean_, self.estd_ = expanded.mean(axis=0), _safe_std(expanded)
477        return (expanded - self.emean_) / self.estd_
478
479    def transform(self, raw):
480        """Apply the learned preprocessing to new rows."""
481        filled = np.where(np.isnan(raw), self.median_, raw)
482        expanded = self.poly_.transform((filled - self.mean_) / self.std_)
483        return (expanded - self.emean_) / self.estd_
484
485
486def _safe_std(a):
487    """Column standard deviations with zeros replaced by 1 (constant columns)."""
488    s = a.std(axis=0)
489    return np.where(s > 0, s, 1.0)

492class PolynomialRidgeRegression:
493    """Ridge regression on polynomial expansions of the environmental features.
494
495    Degree and penalty are chosen jointly by time-ordered cross-validation on the
496    training data (minimum mean absolute error), using :func:`ridge_path_svd` so each
497    candidate degree needs one SVD per fold regardless of how many penalties are tried.
498
499    Parameters
500    ----------
501    degrees : int or sequence of int
502        Candidate polynomial degrees (an int fixes the degree).
503    features : list of str
504        Environmental feature columns (NaN allowed; median-imputed).
505    alphas : array_like
506        Candidate penalties (> 0).
507    inner_splits : int
508        Number of :class:`~sklearn.model_selection.TimeSeriesSplit` folds.
509    name : str, optional
510        Display name.
511
512    Attributes
513    ----------
514    degree_, alpha_ : int, float
515        Selected degree and penalty.
516    n_terms_ : int
517        Number of polynomial terms in the fitted model.
518    cv_mae_ : pandas.DataFrame
519        Inner-CV mean absolute error for every (degree, alpha).
520    coef_ : pandas.Series
521        Coefficients on the standardised polynomial terms.
522    """
523
524    def __init__(self, degrees=config.POLY_DEGREES, features=ENV_FEATURES, alphas=config.RIDGE_ALPHAS,
525                 inner_splits=config.RIDGE_INNER_SPLITS, name=None):
526        self.degrees = (degrees,) if np.isscalar(degrees) else tuple(degrees)
527        if not self.degrees or any(int(d) != d or d < 1 for d in self.degrees):
528            raise ValueError("degrees must be positive integers")
529        self.features = list(features)
530        self.alphas = np.asarray(alphas, float)
531        self.inner_splits = inner_splits
532        if name is None:
533            name = (f"Polynomial ridge (degree {self.degrees[0]})" if len(self.degrees) == 1
534                    else "Polynomial ridge (degree selected by CV)")
535        self.name = name
536
537    def _raw(self, df):
538        """Raw feature array (NaN kept for imputation); raises ``ValueError`` on missing columns."""
539        missing = set(self.features) - set(df.columns)
540        if missing:
541            raise ValueError(f"dataset is missing features: {sorted(missing)}")
542        return df[self.features].to_numpy(float)
543
544    def fit(self, df, y):
545        """Select degree and penalty by inner CV, then refit on all of ``df``. Returns ``self``."""
546        raw, y = self._raw(df), np.asarray(y, float)
547        rows = []
548        for degree in self.degrees:
549            fold_mae = []
550            for tr, va in TimeSeriesSplit(n_splits=self.inner_splits).split(raw):
551                design = _PolynomialDesign(degree)
552                X_tr = design.fit_transform(raw[tr])
553                y_mean = y[tr].mean()
554                B = ridge_path_svd(X_tr, y[tr] - y_mean, self.alphas)
555                pred = np.clip(design.transform(raw[va]) @ B + y_mean, 0, None)
556                fold_mae.append(np.abs(pred - y[va][:, None]).mean(axis=0))
557            rows += [{"degree": degree, "alpha": a, "mae": m}

def ridge_path_svd(X, y, alphas): 
170def ridge_path_svd(X, y, alphas):
171    """Ridge coefficients for many penalties from a single thin SVD.
172
173    With ``X = U S V^T``, the ridge solution for penalty ``alpha`` is
174    ``beta = V diag(s / (s^2 + alpha)) U^T y``. One SVD (~``6 m n^2 + 20 n^3`` flops,
175    Golub & Van Loan, *Matrix Computations*, 4th ed., sec. 8.6) therefore gives every
176    penalty, instead of one factorisation per penalty. Working from the SVD of ``X``
177    rather than ``X^T X`` also avoids squaring the condition number.
178
179    ``X`` and ``y`` should be centred; no intercept is fitted.
180
181    Parameters
182    ----------
183    X : (m, n) array_like
184        Design matrix (any shape; ``n > m`` is allowed).
185    y : (m,) array_like
186        Observations.
187    alphas : array_like
188        Penalties, all > 0.
189
190    Returns
191    -------
192    numpy.ndarray
193        Coefficients, shape ``(n, len(alphas))``.
194    """
195    X, y = np.asarray(X, float), np.asarray(y, float)
196    alphas = np.atleast_1d(np.asarray(alphas, float))
197    if X.ndim != 2 or y.ndim != 1 or X.shape[0] != y.shape[0]:
198        raise ValueError(f"incompatible shapes X{X.shape}, y{y.shape}")
199    if np.any(alphas <= 0):
200        raise ValueError("ridge penalties must be positive")
201    if not (np.isfinite(X).all() and np.isfinite(y).all()):
202        raise ValueError("X and y must not contain NaN or inf")
203    U, s, Vt = np.linalg.svd(X, full_matrices=False)
204    shrink = s[:, None] / (s[:, None] ** 2 + alphas[None, :])   # (k, n_alphas)
205    return Vt.T @ (shrink * (U.T @ y)[:, None])

540        missing = set(self.features) - set(df.columns)
541        if missing:

546        """Select degree and penalty by inner CV, then refit on all of ``df``. Returns ``self``."""
